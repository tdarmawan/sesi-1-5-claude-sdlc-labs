# Sesi 1 — Foundations, Agent & Workflow
Kasus mandiri: **Reset Password**. Sesi 2–5 memakai WebTM; jangan mencampur knowledge kedua kasus.

1. Baca BRD.md, USER-FLOW.md, API-SPEC.md. Buat Project "SDLC - Reset Password" dan tambahkan ketiganya.
2. Tempel PROJECT-INSTRUCTIONS.md. Jalankan empat variasi prompt dalam PROMPTS.md di chat baru.
3. Isi OUTPUT-STARTER.json. Bandingkan dengan CHECKPOINT-01.json (draft) dan CHECKPOINT-02.json (hasil review).
4. Di chat lain, gunakan sdlc-review.SKILL.md atau pasang sdlc-review.zip. Cocokkan tiap klaim terhadap sumber.
5. Isi REVIEW-LOG.md dan SCORECARD.md. Tandai asumsi/gap dan jangan menganggap Needs Clarification sebagai Approved.

Hasil: Project, knowledge pack, user story/AC terstruktur dan review log. Tidak perlu aplikasi backend.
Checkpoint sengaja menyimpan pertanyaan yang belum diputuskan. Validasi lokal dari root: `npm test`.
