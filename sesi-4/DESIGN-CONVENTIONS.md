# Design conventions
Warna: teks #18364a, sidebar #102c42, aksi utama #136c62, latar #f2f6fa, error #b32937.
Font system-ui; body 16px; label jelas; spacing dasar 8px; card radius 12px.
Satu aksi utama per screen. Tabel konsisten ID/Name/Total User/Status.
Input/aksi memiliki label terlihat, fokus keyboard jelas; error dekat field dan diumumkan secara aksesibel.
State tidak bergantung warna saja; selalu tampilkan teks. Pada layar sempit form menjadi satu kolom.
Permission dikelompokkan per menu/submenu; default TBC, tidak otomatis diwariskan.
