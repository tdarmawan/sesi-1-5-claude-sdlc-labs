# Layout A/B — checkpoint penilaian
A: dua kolom, identitas di kiri dan permission panjang di kanan. B: satu halaman dengan section berurutan.
| Kriteria | A | B |
|---|---|---|
| Urutan flow | Identitas dan permission sejajar, urutan mudah terlewat | Urutan identitas → permission → Submit jelas |
| Kelengkapan | Semua field ada | Semua field ada |
| Aksi utama | Terpisah dari permission | Berada setelah section terakhir |
| State/error | Ruang error sempit | Pesan dekat field, ruang cukup |
| Keterbacaan permission | Kolom cenderung padat | Lebar penuh untuk group menu |
Contoh keputusan: pilih B untuk daftar permission panjang. Peserta boleh memilih A dengan alasan dan uji state yang memadai.
Feedback berikutnya: satu hal spesifik, misalnya kelompokkan submenu dan pertahankan pesan error di bawah Role Name.
