# Sesi 4 — UI Exploration & Development Handoff
Rujukan lama `training/session-2/hands-on-2/` kini **sesi-4/**.
Input awal: [BRD Sesi 2](../sesi-2/BRD-v1.2.md) dan [flow Sesi 3](../sesi-3/FLOW-CHECKPOINT-v2.md).
Screen dan layout terpilih adalah **hasil HO1**, baru menjadi input HO2.

## HO1 — Eksplorasi UI (75 menit)
Pasang ui-brief.zip, jalankan PROMPTS.md tahap A. Nilai enam cek di SCORECARD.md.
Jalur Stitch: ikuti MCP-SETUP.md. Alternatif: tempel prompt desain di Claude Design, atau kerjakan wireframe manual.
Bandingkan LAYOUT-A.svg dan LAYOUT-B.svg memakai LAYOUT-REVIEW.md; pilih satu berdasarkan bukti.
Checkpoint: UI-BRIEF-CHECKPOINT.md dan empat screen SVG (list/create/members/log).

## HO2 — Refinement & handoff (75 menit)
1. Baca temuan HO1 dan arah terpilih; ubah satu hal dengan alasan yang jelas.
2. Terapkan DESIGN-CONVENTIONS.md, jangan mengulang setup Skill.
3. Periksa REQUIREMENT-SCREEN.csv. Selesaikan mapping atau beri catatan gap.
4. Isi DESIGN-SPEC-TEMPLATE.md; bandingkan dengan HANDOFF-CHECKPOINT.md.
5. Walkthrough screen, state, validasi, permission, dependency dan OPEN-ISSUES.md.

Hasil: screen refined, conventions, mapping, design spec, daftar keputusan terbuka.
Ekspor screenshot/HTML dari alat desain yang dipakai dan simpan untuk Sesi 5. Jika ekspor gagal, pakai SVG acuan.
Paket tidak menyertakan API key dan tidak membuat/mengubah project Stitch atau Miro pengguna secara otomatis.
