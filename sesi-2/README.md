# Sesi 2 — Review-Ready BRDs with Claude
Nomor mengikuti nama file slide. Rujukan lama `training/session-1/` kini dipetakan ke **sesi-2/**.
Kasus seluruh latihan berikutnya: WebTM Role & User Management; scope latihan BRD Role Management.

## Hands-on 1 (50 menit)
1. Salin BRD-TEMPLATE.md ke Google Docs milik sendiri atau file lokal. Baca PRODUCT-CONCEPT.md dan REFERENCE-BRD.md.
2. Buat Project WebTM dan isi PROJECT-INSTRUCTIONS.md. Gunakan PROMPTS.md tahap 1–5.
3. Lengkapi description brd-draft-starter.SKILL.md, lalu pasang lewat fitur Skills. Checkpoint: brd-draft-v1.zip.
4. Lampirkan BRD-STRUCTURE.md sebagai referensi. Tinjau draft sebelum mengizinkan penulisan ke Docs.
5. Periksa delapan bagian BRD. BRD-v1.0.md adalah checkpoint draft untuk latihan gap, bukan contoh final.

## Hands-on 2 (30 menit)
Pasang brd-review.zip, bandingkan BRD-v1.0.md terhadap PRODUCT-CONCEPT.md; Reference BRD hanya acuan struktur.
Jalankan review, periksa kutipan nyata, ajukan satu pertanyaan per gap dengan owner.
Checkpoint: GAP-CHECKPOINT.md; isi SCORECARD.md dari hasil aktual.

## Hands-on 3 (50 menit)
Baca MEETING-NOTES.md. Salin v1.0 menjadi v1.1, ubah hanya keputusan disetujui.
Pilih dua temuan berulang, perbaiki Skill ke v2 lalu dokumen ke v1.2. Bandingkan bukti.
Checkpoint: BRD-v1.1.md, brd-draft-v2.zip, BRD-v1.2.md. TBC tetap terbuka.
Pakai BRD-v1.2.md untuk Sesi 3–5; versi 1.1-lab di Sesi 5 adalah snapshot scope prototype dengan aturan sama.

Google Docs/Claude memerlukan akun peserta; bila connector tidak tersedia, pakai Markdown lokal dan review manual.
Tidak ada akun/token/API key yang disediakan paket. Hasil generasi AI bisa berbeda; nilai dengan rubrik tetap.
