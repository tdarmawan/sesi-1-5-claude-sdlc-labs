Rujukan lama `training/session-2/hands-on-1/` dipetakan ke **sesi-3/**.
Input: BRD akhir Sesi 2 atau [checkpoint](../sesi-2/BRD-v1.2.md), flow Create New Role.
1. Buat board Miro latihan, sambungkan connector Miro dan Google Docs pada akun sendiri.
2. Pasang flow-diagram-v1.zip atau tempel flow-diagram-v1.SKILL.md pada fitur Skills.
3. Jalankan PROMPTS.md. Review flow spec sebelum menggambar. Isi SCORECARD.md v1.

5. Setelah disetujui, gambar di board latihan; cocokkan tiap node/edge ke flow spec. Tautkan hasil ke bagian 6 BRD salinan.
