# Prompt hands-on
## HO1
1. "Baca Product Concept dan Reference BRD. Ringkas scope Role Management dan sumber masing-masing."
2. "Analisis delapan bagian template dan konvensi Reference BRD. Tampilkan tabel bagian/tujuan/contoh. Jangan menulis dokumen."
3. "Lengkapi hanya description starter brd-draft, maksimal 450 karakter. Pertahankan instruksi lain."
4. Pasang Skill melalui fitur Skills: tempel nama, description, body dan tambah referensi BRD-STRUCTURE.md.
   Alternatif upload brd-draft-v1.zip. Jika memakai file di Code, ekstrak ke folder Skill yang sesuai dokumentasi akun.
5. "/brd-draft Susun draft dari PRODUCT-CONCEPT.md untuk salinan [LINK BRD]. Tampilkan dulu; jangan tulis sebelum disetujui."
## HO2
"/brd-review Bandingkan BRD-v1.0 dengan Product Concept. Tiap gap punya ID, jenis, bagian, kutipan nyata,
sumber pembanding, satu pertanyaan dan owner. Nilai delapan cek, jangan mengarang kutipan."
Periksa kutipan minimal tiga gap atau seluruh gap bila kurang dari tiga. Catat temuan salah kutip.
## HO3
"Gunakan meeting M-01..04 yang disetujui untuk salinan v1.1. M-05/06 tetap TBC. Tampilkan perubahan sebelum menulis."
"Review v1.1; pilih dua temuan berulang, usulkan dua aturan Skill beserta bukti. Tunggu persetujuan."
"Sesudah aturan disetujui, ulangi sebagai v1.2; bandingkan delapan cek dengan versi sebelumnya."
Jika slash command tidak dikenali, panggil nama Skill eksplisit dan lampirkan instruksinya; cek Skill telah aktif.
